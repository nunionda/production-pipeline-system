# Korean Call Sheet Reference (콜시트 / 일일촬영계획표)

> Reference document for nunionda Sprint 2 PDF generation.
> Compiled from Korean film industry sources, template repositories, and production manuals.

---

## 1. Terminology

| Korean | English | Notes |
|--------|---------|-------|
| 일일촬영계획표 | Daily Shooting Plan | Formal name, used on the document itself |
| 일촬표 | Daily sheet (abbrev.) | Colloquial shorthand used on set |
| 콜시트 | Call sheet | Konglish loan word, widely understood |
| 콜타임 | Call time | When cast/crew must arrive |
| 촬영회차 | Shooting day number | e.g. "제12촬영일" |

### Who writes it

The **2nd AD (세컨, 세컨드)** drafts the call sheet. It is reviewed and approved by the **1st AD (퍼스트)**, then the **PD/제작부장**, and finally the **감독 (Director)**. Once distributed to cast and crew, changes are considered unprofessional and avoided whenever possible.

## 2. Standard Sections (top to bottom)

A Korean call sheet is a single-page (occasionally two-page) document, typically landscape-oriented, with a dense table layout. The canonical section order is:

### Section A: Header (헤더)

| Field | Korean | Example |
|-------|--------|---------|
| Production title | 작품명 | 눈이 온다 |
| Episode number | 회차 | 제3회 (drama only) |
| Shooting day | 촬영회차 | 제12촬영일 |
| Date | 촬영일 | 2026년 3월 26일 (목) |
| Weather | 날씨 | 맑음 / 흐림 / 우천시 대안: S#42 |
| Author | 작성자 | 김세컨 |

**Key crew contacts (right side of header):**

| Role | Korean |
|------|--------|
| Director | 감독 |
| 1st AD | 조감독 (퍼스트) |
| 2nd AD | 세컨드 |
| Producer/PD | 제작부장 / PD |
| DOP | 촬영감독 |
| Lighting Director | 조명감독 |

Each entry includes name + mobile number.

### Section B: Assembly Info (집합사항)

| Field | Korean | Example |
|-------|--------|---------|
| Assembly time | 집합시간 | 06:00 |
| Assembly location | 집합장소 | 서울 마포구 상암동 XX스튜디오 |
| Shoot start time | 촬영시작 | 08:00 |
| Lunch time | 점심시간 | 12:00 - 13:00 |
| Wrap (est.) | 예상종료 | 22:00 |
| Nearest hospital | 인근병원 | XX병원 (02-XXX-XXXX) |

### Section C: Scene Schedule (장면내용) -- Main Table

This is the core of the call sheet. Each row represents one scene to be shot that day.

**Column structure:**

| Column | Korean | Description |
|--------|--------|-------------|
| Scene number | S# | e.g. S#42 |
| Location (script) | 장소 | Script location name, e.g. "민수의 집 - 거실" |
| Shooting location | 촬영지 | Actual location/set name |
| Set type | S/L/O | S=Set, L=Location, O=Open set (see below) |
| INT/EXT | I/E | INT (실내) / EXT (실외) |
| Time of day | M/D/N | Time-of-day code (see below) |
| Shot count | 컷수 | Number of shots/setups planned |
| Page count | 매수 | Script pages (in 1/8 increments) |
| Scene description | 장면내용 | Brief action summary |
| Characters | 등장인물 | Character names or cast numbers |
| Extras | 단역/보조출연 | Extra/bit-part requirements |
| Notes | 비고 | Special requirements |

### Section D: Department Notes (파트별 사항)

Horizontal sub-tables or rows for each department's needs per scene:

| Department | Korean | Typical entries |
|------------|--------|-----------------|
| Art/Set design | 미술 | Set dressing, set changes between scenes |
| Props | 소품 | Specific props needed per scene |
| Costumes | 의상 | Costume changes, special wardrobe |
| Makeup/Hair | 분장/헤어 | Special makeup, aging, wounds, wigs |
| CG/VFX | CG | Green screen, motion capture markers |
| Special makeup | 특분 (특수분장) | Prosthetics, creature effects |
| SFX | 특효 (특수효과) | Rain, fire, explosions, breakaway |
| Camera | 촬영 | Special rigs: crane, steadicam, drone |
| Lighting | 조명 | Special lighting setups, generator needs |
| Sound | 동시녹음 | Boom/lav needs, playback, wild tracks |

### Section E: Cast Call Times (연기자)

Table listing every actor needed that day:

| Column | Korean | Description |
|--------|--------|-------------|
| Character name | 배역 | e.g. 민수 |
| Actor name | 배우명 | e.g. 이영수 |
| Call time | 콜타임 | e.g. 06:00 |
| Pickup time | 픽업 | Vehicle pickup time |
| Makeup/Hair time | 분장 | e.g. 06:30 |
| Standby time | 대기 | Ready on set time |
| Scenes | 출연씬 | S#42, S#45, S#47 |
| Notes | 비고 | Wardrobe change, stunt double needed |

### Section F: Extras/Bit Parts (보조출연)

| Column | Korean | Description |
|--------|--------|-------------|
| Role description | 역할 | e.g. 카페 손님 |
| Count | 인원 | e.g. 15명 |
| Call time | 집합시간 | e.g. 08:00 |
| Location | 집합장소 | Where extras report |
| Costume note | 의상 | e.g. 평상복 / 제공 |
| Scenes | 해당씬 | S#42 |

### Section G: Timetable (타임테이블)

Hour-by-hour breakdown of the day:

```
06:00  집합 / 장비 셋업
07:00  배우 분장
08:00  S#42 촬영
10:00  S#45 촬영
12:00  점심
13:00  장소이동 (상암 → 이태원)
14:00  S#47 촬영
...
22:00  촬영종료 (예정)
```

### Section H: Department Contacts (파트별 연락처)

Grid of department heads with mobile numbers:

| 연출 | 촬영 | 조명 | 미술 | 의상 | 분장 | 소품 | 특효 | 동시녹음 | 제작 |
|------|------|------|------|------|------|------|------|----------|------|
| name | name | name | name | name | name | name | name | name | name |
| phone | phone | phone | phone | phone | phone | phone | phone | phone | phone |

## 3. Notation Conventions

### Time of Day (시간대)

| Code | Korean | Meaning | Typical hours |
|------|--------|---------|---------------|
| D | 낮 | Daytime | ~09:00-17:00 |
| N | 밤 | Night | ~19:00-05:00 |
| D/N | 저녁 | Dusk / evening | ~17:00-19:00 |
| N/D | 새벽 | Dawn / pre-dawn | ~05:00-07:00 |
| M | 아침 | Morning | ~07:00-09:00 |

### Set Type (촬영지 구분)

| Code | Korean | Meaning |
|------|--------|---------|
| S | 세트 | Purpose-built studio set |
| L | 로케이션 | Real exterior location (street, park) |
| O | 오픈세트 | Real interior used as-is (cafe, office) |

### INT/EXT (실내외)

| Code | Korean | Meaning |
|------|--------|---------|
| INT | 실내 | Interior |
| EXT | 실외 | Exterior |
| INT/EXT | 실내/실외 | Scene spans both |

### Page Count (매수)

Script length is measured in **1/8 page increments**, following the Hollywood standard adopted in Korean production. A full page = 8/8. Common notation: `2 3/8` means 2 and 3/8 pages.

## 4. Film vs. Drama Differences

| Aspect | Film (영화) | Drama (드라마) |
|--------|------------|---------------|
| Episode field | Not used | 회차 (episode number) is prominent |
| Shooting day ID | 제N촬영일 (absolute day) | 회차 + 촬영일 (episode-relative) |
| Schedule density | 2-5 scenes/day typical | 5-15 scenes/day (tighter schedules) |
| Page count | Always tracked | Sometimes omitted |
| Weather contingency | Detailed rain cover plan | Often handled via studio fallback |
| Extras volume | Can be hundreds | Usually smaller |
| Distribution | Printed + group chat | Primarily via KakaoTalk group |
| Department detail | More granular (VFX, SFX, stunts) | Lighter (fewer special departments) |
| Document format | Single-page landscape | Single-page, sometimes portrait |
| Approval chain | 세컨 → 퍼스트 → 제작부장 → 감독 | 세컨 → 퍼스트 → PD |
| Revision tracking | Version number on sheet | Less formal |

### Web Drama / Short Film

Simplified versions often merge sections D-F into a single notes column. The header and scene schedule remain structurally identical.

## 6. Mapping to nunionda Data Model

The current Prisma schema already covers many call sheet fields. Here is the mapping
and what may need to be added for PDF generation:

| Call Sheet Field | Prisma Model/Field | Status |
|------------------|--------------------|--------|
| 작품명 | `Project.title` | Exists |
| 회차 | -- | Needs addition (episode tracking) |
| 촬영회차/날짜 | `ShootingDay.date` + `sortOrder` | Exists |
| 날씨 | `ShootingDay.weatherPlan` | Exists (rain plan only, add forecast) |
| 집합시간 | `ShootingDay.callTime` | Exists |
| 촬영시작 | `ShootingDay.shootTime` | Exists |
| 점심시간 | `CallSheet.meals` (JSON) | Exists |
| 예상종료 | -- | Add to `ShootingDay` or `CallSheet` |
| 인근병원 | -- | Add to `CallSheet` or `Location` |
| S# | `Scene.number` | Exists |
| 장소 | `Scene.location` | Exists |
| 촬영지 | `Location.realName` / `Location.address` | Exists |
| S/L/O | -- | Add enum to `Location` |
| INT/EXT | `Scene.intExt` (INT, EXT, INT_EXT) | Exists |
| D/N | `Scene.timeOfDay` (D, N, DN, ND) | Exists |
| 컷수 | Count of `Shot` per scene | Derivable |
| 매수 | `Scene.pageCount` | Exists |
| 장면내용 | `Scene.description` | Exists |
| 등장인물 | `SceneCharacter` join | Exists |
| 보조출연 | -- | Needs addition (extras model) |
| 파트별 사항 | `CallSheet.equipment` (JSON) | Partially exists |
| 미술/소품/의상/분장 | Entity models exist | Need per-scene notes for call sheet |
| CG/특분/특효 | `VFX` + `SceneVFX` | Exists (may need subtype) |
| 촬영/조명 | -- | Add to department notes |
| 연기자 콜타임 | `CallSheet.cast` (JSON) | Exists (structured JSON) |
| 타임테이블 | `CallSheet.scenes` (JSON) | Partially exists |
| 파트별 연락처 | `ProjectMember` + `User` | Derivable |

### Recommended Schema Additions for Sprint 2

1. **Episode tracking**: Add `episode Int?` to `ShootingDay` or create `Episode` model
2. **Extras model**: `Extra` with role description, count, costume note
3. **Location set type**: Add `setType` enum (SET, LOCATION, OPEN_SET) to `Location`
4. **Estimated wrap time**: Add `wrapTime String?` to `ShootingDay`
5. **Nearest hospital**: Add `nearestHospital String?` to `CallSheet`
6. **Department notes**: Consider structured JSON or a `DepartmentNote` model with per-scene, per-department entries
7. **Cast call details**: Expand `CallSheet.cast` JSON schema to include pickup time, makeup time, standby time

## 7. PDF Layout Recommendations

- **Orientation**: Landscape A4 (가로)
- **Font**: Nanum Gothic or Pretendard (Korean web-safe)
- **Font size**: 8-9pt for table body, 10-11pt for headers
- **Grid lines**: Thin solid borders on all cells (Korean convention is dense grid)
- **Color**: Minimal -- header row background in light gray, department sections in alternating light tints
- **Page limit**: Aim for single page; overflow to second page only for cast/extras on large-scale shoots
- **File naming convention**: `일촬표_[작품명]_[촬영회차]_[날짜].pdf`
  - Example: `일촬표_눈이온다_D12_20260326.pdf`
